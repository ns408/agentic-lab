# Security policy

This is a public demonstration repository. It is not production software and ships
with no warranty (see [LICENSE](LICENSE)).

## Reporting a vulnerability

Please report security issues privately, not through public issues or pull requests.

- Use GitHub private vulnerability reporting: the repository **Security** tab, then
  **Report a vulnerability**.

Reports are acknowledged within a few days. Please do not include real secrets or
credentials in a report; redact them first.

## Scope

In scope: the demo apps, build tooling, and CI in this repository. Out of scope:
third-party dependencies and local model runtimes (report those upstream).
